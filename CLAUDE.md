# QuizLab

Веб-приложение «викторина»: лендинг и 10 вопросов с подсчётом баллов. Next.js 16 (App Router), TypeScript, Tailwind CSS 4. Интерфейс на русском языке.

@AGENTS.md

## Стиль и дизайн

Перед любой работой с интерфейсом (вёрстка, цвета, шрифты, анимации, новые компоненты) прочитай разбор стиля и следуй ему:

@style.md

Правила:

- Файл `style.md` — обязательный источник по дизайну для всех сессий. Новые экраны и компоненты оформляй в духе его разделов «Композиция», «Палитра», «Типографика» и «Компоненты».
- Разбор в `style.md` описывает сторонний референс. Актуальное оформление описано в разделе 21 «Что применено в QuizLab»: тёмный графитовый фон, терракотовый акцент, узкий заглавный шрифт, прямые углы и тонкие линии (референс «Visit Tokyo», разделы 12–20). Талисман и анимации сохраняются. Разделы 1–11 относятся к прежнему голубо-розовому оформлению. Есть две темы, тёмная и светлая (переключатель `ThemeToggle`; цвета только через токены). Остальное (фотофоны) применяй только по прямой просьбе.
- Если пользователь просит изменить стиль, сначала сверься с `style.md`, а после изменений обнови его, чтобы файл не расходился с кодом.

## Структура

- `app/` — страница и общие стили (`globals.css`: цвета-токены и анимации в `@theme`).
- `components/` — `Quiz.tsx` (оболочка с переключателем режимов «Ученик» / «Преподаватель»), `ModeSwitch.tsx`, `StudentStudio.tsx` (викторина и тесты учителя), `Builder.tsx` (студия преподавателя: «Мои тесты», «Создать тест», «Прохождение»), `Player.tsx` (состояния: лендинг, вопрос, результат; бывший `Quiz.tsx`), `lib/storage.ts` (тесты и результаты в `localStorage`), `Landing.tsx`, `Result.tsx`, `Mascot.tsx` (улыбка и грусть), `Reveal.tsx` (появление при прокрутке), `FormulaBackground.tsx`.
- `lib/questions.ts` — вопросы викторины; новые вопросы добавляются в этот массив.

## Соглашения

- Весь видимый текст на русском; `lang="ru"` стоит в `app/layout.tsx`.
- Анимации заданы в `globals.css` (`animate-fade-up`, `animate-pop`, `animate-shake` и др.). Каждый новый элемент интерфейса анимируй так же, как соседние, и учитывай `prefers-reduced-motion`.
- Цвета бери из токенов (`background`, `surface`, `line`, `muted`, `accent`, `accent-soft`, `foreground`), а не из случайных HEX-кодов.

## Запуск

Папка называется `QuizLab` с заглавными буквами, поэтому `create-next-app` в ней не работает, а проект уже создан. Node.js установлен в `C:\Program Files\nodejs`, но может отсутствовать в PATH. Если `npm` не найден, в PowerShell перед командой выполни:

```powershell
$env:Path += ";C:\Program Files\nodejs"
```

```bash
npm run dev
```

Проверка перед завершением работы: `npx tsc --noEmit` и `npx eslint .`.
